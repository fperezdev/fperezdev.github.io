Selected work

Two systems you can inspect today: one runs a small business end to end, the other is infrastructure that has to be right when something breaks.

  1. AI Automation Suite

    n8n · FastAPI · PostgreSQL · WhatsApp Cloud API

    Four automation modules built around one real client — a dental clinic in Ñuñoa that ran everything by hand: invoices typed into a spreadsheet, WhatsApp answered between patients, leads lost in the inbox. The suite covers invoices, WhatsApp and webchat support, lead scoring and monthly sales reports, sharing one database and one panel. A fifth system, FlowWatch, covers the alerting side.

    Every module ships with its own 30-case golden set and a reproducible evaluation, so the numbers on this page are measured, not claimed. Figures are computed by pure functions; the LLM only writes the prose. Runs with one command, no API keys, using a deterministic mock model.

    Repository Invoice case WhatsApp case Live site

  2. FlowWatch

    Go · Next.js · MongoDB · Redis · k3s

    Alerting for data pipelines: an ingestor that takes events over HTTP, a worker that fires when the same rule fails three times in a row, and a panel that shows every run, including the empty and error states. Built to survive its own infrastructure — two replicas, persistent volumes, a 20 MB distroless image.

    Verified the way production systems should be: a 30-case deterministic evaluation at 30/30, and a pod-kill test at 400 out of 400 events processed with no losses.

How I work

In writing. Requirements, decisions and delivery happen in text: a spec you can read twice, a short recorded demo instead of a call, documentation per module. Async across time zones, in Spanish or English.

Small first release. One process, running on your real data, in days. Then the next one. No six-month platform before anything works.

Numbers before adjectives. If a module claims to be accurate, it comes with the set that proves it and the command that reproduces it.

Deterministic where money is involved. Amounts, percentages and scores are computed; the model writes the sentence around them, never the figures.

Documented handover. Repository, README per module, and the operational notes your team needs to run it without me.
