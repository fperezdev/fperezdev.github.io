Trabajo seleccionado

Dos sistemas que puedes revisar hoy: uno opera un negocio completo, el otro es infraestructura que tiene que responder bien cuando algo falla.

  1. AI Automation Suite

    n8n · FastAPI · PostgreSQL · WhatsApp Cloud API

    Cuatro módulos de automatización armados sobre un cliente real: una clínica dental en Ñuñoa que atendía todo a mano. Facturas escritas en una planilla, WhatsApp respondido entre pacientes, consultas perdidas en la bandeja. La suite cubre facturas, soporte por WhatsApp y webchat, calificación de leads y reportes de ventas, con una sola base de datos y un solo panel. Un quinto sistema, FlowWatch, cubre la parte de alertas.

    Cada módulo trae su set dorado de 30 casos y una evaluación reproducible, así que los números de esta página están medidos, no prometidos. Las cifras las calculan funciones puras; el LLM solo redacta. Corre con un comando, sin API keys, con un modelo mock determinista.

    Repositorio Caso facturas Caso WhatsApp Sitio

  2. FlowWatch

    Go · Next.js · MongoDB · Redis · k3s

    Alertas para pipelines de datos: un ingestor que recibe eventos por HTTP, un worker que dispara cuando la misma regla falla tres veces seguidas y un panel que muestra cada corrida, incluidos los estados vacío y error. Construido para sobrevivir a su propia infraestructura: dos réplicas, volúmenes persistentes, imagen distroless de 20 MB.

    Verificado como corresponde: evaluación determinista de 30 casos en 30/30 y prueba de caída de pod con 400 de 400 eventos procesados sin pérdidas.

  3. Ingeniería de producto

    React · Next.js · Supabase · Node.js

    Antes de la automatización pasé cinco años entregando productos web: front end en React y Next.js, datos en Supabase y PostgreSQL, integraciones REST y GraphQL. Por eso las automatizaciones de arriba terminan en un panel usable y no en una carpeta de scripts.

Cómo trabajo

Por escrito. Requisitos, decisiones y entrega en texto: una especificación que puedes leer dos veces, una demo grabada corta en vez de una llamada y documentación por módulo. Asíncrono, en español o inglés.

Primera entrega chica. Un proceso funcionando con tus datos reales en días, después el siguiente. Sin plataforma de seis meses antes de que algo funcione.

Números antes que adjetivos. Si un módulo dice ser exacto, viene con el set que lo prueba y el comando que lo reproduce.

Determinista donde hay dinero. Montos, porcentajes y scores se calculan; el modelo redacta la frase alrededor, nunca las cifras.

Traspaso documentado. Repositorio, README por módulo y las notas de operación que tu equipo necesita para correrlo sin mí.
